# AXIS

AXIS(액시스)는 고교 교육과정의 수학·과학 개념을 **시뮬레이션 모션 + 그래프 + 수치 표현**으로 통합해 보여주는 하이엔드 웹 유틸리티입니다. Apple식 미니멀리즘과 글래스모피즘 UI를 바탕으로, 복잡한 개념을 직관적인 상호작용으로 학습·탐구할 수 있는 디지털 실험실을 목표로 합니다.

## 1) 프로젝트 목표

- 추상적 수식과 과학 개념을 “살아있는 시각화”로 전환
- 학습자에게 매일 사용하고 싶은 고품질 인터랙티브 도구 제공
- 교육용 정확성과 실무형 유틸리티를 하나의 제품으로 통합

## 2) 핵심 UX/디자인 원칙

### Extreme Minimalism & Glassmorphism
- 불필요한 UI 요소를 제거해 핵심 정보 집중
- 반투명 레이어와 깊이감 있는 인터페이스로 고급스러운 사용감 제공

### Multiple Representations
- 동일 현상을 아래 3가지 관점으로 동시 제시
  - 시뮬레이션 모션
  - 그래프 (시간/변수 기반)
  - 숫자/막대/테이블

### Real-time Sliders & Kinetic UX
- 모든 핵심 변수를 슬라이더로 즉시 제어
- 입력 지연 없는 피드백과 부드러운 모션 반응 제공

## 3) 기능 범위 (고교 교육과정 기반)

### 📐 Mathematics: The Logic

1. **Interactive Graphing**
   - 다중 함수 실시간 렌더링
   - 파라미터 \(a,b,c\) 슬라이더 조정
   - 교점/극대/극소 자동 탐지 및 테이블 뷰
2. **Geometry & Transform**
   - 점·선·면 자유 구성
   - 각도/넓이 자동 측정
   - 이동·회전·대칭 변환 애니메이션
3. **Trigonometry Explorer**
   - 단위원에서 동경 이동
   - \(\sin, \cos, \tan\) 값 변화와 그래프 동기화
4. **Step-by-Step Solver**
   - 방정식/부등식/미적분 풀이 과정을 최소 모션으로 시각화

### 🍎 Physics: The Kinetic World

1. **Motion Simulator**
   - 포물선, 자유낙하, 등가속도 운동
   - 초기속도/각도/중력 조절
   - 벡터 및 \(s-t, v-t\) 그래프 연동
2. **Energy Playground**
   - 위치에너지-운동에너지 변환
   - 마찰 유무 비교
   - 에너지 막대 그래프 동시 표시
3. **Force & Newton's Laws**
   - 힘 벡터 드래그 적용
   - 질량·힘에 따른 가속도 실시간 반영
4. **Circuits & Waves**
   - 전지·저항 회로 기초 구성 및 측정
   - 진폭/주파수 조절에 따른 진행파·정재파 렌더링

### 🧪 Chemistry: The Micro Interaction

1. **Smart Periodic Table**
   - 원소 정보(전자배치 등) 제공
   - 그룹/주기 필터링
2. **3D Molecule Viewer**
   - VSEPR 기반 주요 분자 구조 회전
   - 결합각 확인 (예: \(H_2O\), \(CH_4\))
3. **Reaction & Balance**
   - 반응식 자동 균형(Balancing)
   - 온도/농도 변화에 따른 반응 속도(충돌 이론) 입자 시뮬레이션

### 🔭 Astronomy: The Cosmic Scale

1. **Solar System Orrery**
   - 케플러 법칙 기반 공전 궤도 모델
   - 시간 가속 인터랙션
2. **Phase & Eclipse**
   - 지구-달-태양 배치에 따른 위상/식 현상 시각화
3. **Constellation Viewer**
   - 계절별 주요 별자리 지도
   - 천구상 위치 데이터 제공

## 4) Daily Essentials (실무형 유틸리티)

- **Smart Quick Solver**: 수식 풀이, 단위 변환, 데이터 검색 통합 입력
- **Scientific Converter**: \(eV \leftrightarrow J\), \(ly \leftrightarrow pc\), \(atm \leftrightarrow Pa\)
- **Reference & Tools**: 상수 테이블, Ruler/Stopwatch/Voltmeter, URL 공유/저장

## 5) 제품 방향성

AXIS는 단순 계산기가 아닌, “개념을 움직임으로 이해하는” 차세대 학습 플랫폼을 지향합니다. 향후에는 개인화 학습 경로, 실험 기록 내보내기, 교실 단위 협업 기능을 통해 교육 현장 적용성을 확장합니다.
